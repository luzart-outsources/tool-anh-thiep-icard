Bàn làm việc thiệp

Tool chạy ngay trên máy của bạn, mở bằng trình duyệt. Làm theo 3 bước dưới đây – chỉ lần đầu hơi lâu, từ lần sau mở trong vài giây.

1. Giải nén

  1. Bấm đúp file .zip vừa tải → hiện thư mục ThiepTool.
  2. Kéo thư mục đó vào Tài liệu (Documents) hoặc Màn hình nền cho dễ tìm.

2. Mở tool

  1. Mở thư mục ThiepTool, bấm đúp Mở Tool (Mac).
  2. Lần đầu máy Mac sẽ chặn vì tool chưa đăng ký với Apple. Bạn chỉ cần cho phép một lần:
    • macOS 15 (Sequoia) trở lên: bấm Xong ở thông báo → mở Cài đặt hệ thống → Quyền riêng tư & Bảo mật → kéo xuống dưới cùng → bấm Vẫn mở (Open Anyway) cạnh dòng "Mở Tool (Mac)" → nhập mật khẩu máy → bấm Mở.
    • macOS 14 trở về trước: bấm chuột phải (hoặc giữ Control rồi bấm) vào Mở Tool (Mac) → chọn Mở → bấm Mở lần nữa.
  3. Cửa sổ Terminal (nền đen/trắng có chữ) hiện ra – đó là tool đang chạy.

1. Giải nén

  1. Bấm chuột phải vào file .zip → Extract All… (Giải nén tất cả) → Extract.
  2. Không mở tool khi còn ở trong file zip – phải giải nén trước.

2. Mở tool

  1. Mở thư mục ThiepTool, bấm đúp Mở Tool (Windows).
  2. Nếu hiện "Windows protected your PC": bấm More info → Run anyway.
  3. Cửa sổ đen có chữ hiện ra – đó là tool đang chạy.

3. Lần đầu: chờ tool tự cài (3–5 phút)

  1. Lần đầu cần có mạng: tool tự tải và cài những gì cần (khoảng 150–300 MB), không cần bạn làm gì.
  2. Xong, trình duyệt tự mở trang Bàn làm việc thiệp. Bắt đầu bằng nút ✦ Thiết kế mới.
  3. Từ lần sau: bấm đúp Mở Tool là vào ngay.
Quan trọng: đừng đóng cửa sổ Terminal / cửa sổ đen trong lúc đang dùng tool – đóng nó là tool tắt. Dùng xong: đóng trình duyệt rồi đóng cửa sổ đó. Lỡ đóng trình duyệt thì mở lại địa chỉ http://127.0.0.1:8800.

Dữ liệu của bạn ở đâu?

Mọi mẫu thiệp, font tự thêm và thiệp đã xuất nằm ở thư mục Tài liệu (Documents) › ThiepTool – thiệp xuất ra ở ThiepTool/output.

Nhận bản tool mới: xoá thư mục tool cũ, giải nén bản mới, mở lại – dữ liệu trong Documents/ThiepTool vẫn còn nguyên.

Cần có

  • Máy Mac (chip Apple hoặc Intel) hoặc Windows 10/11, còn trống khoảng 1 GB.
  • Mạng internet ở lần mở đầu tiên.
  • Tài khoản ChatGPT có vẽ ảnh – để AI thiết kế và vẽ hoa văn (tool dẫn từng bước).

Gỡ tool

Xoá thư mục tool, rồi xoá bộ chạy: Mac – ~/Library/Application Support/ThiepTool (Finder › Đi › Đi tới thư mục…); Windows – %LOCALAPPDATA%\ThiepTool. Dữ liệu của bạn (Documents/ThiepTool) xoá hay giữ tuỳ bạn.
